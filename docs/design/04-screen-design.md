# 画面設計書

## 1. 概要

本書は、設備点検管理システムの各画面について、目的、表示項目、入力項目、操作、遷移先、および簡易ワイヤーフレームを定義する。

画面番号は `01-screen-transition.drawio` に記載した番号と共通とする。

---

## 2. 共通仕様

### 2.1 共通レイアウト

ログイン後の業務画面は、原則として次の共通レイアウトを使用する。

```text
+------------------------------------------------------------------+
| 設備点検管理システム                         ログインユーザー名    |
|                                              [ログアウト]        |
+------------------------------------------------------------------+
| 画面タイトル                                                     |
+------------------------------------------------------------------+
|                                                                  |
| 画面固有コンテンツ                                               |
|                                                                  |
+------------------------------------------------------------------+
```

### 2.2 権限

| 権限        | 説明                                                                               |
| ----------- | ---------------------------------------------------------------------------------- |
| `ADMIN`     | 設備・点検項目の登録・編集、点検実施、履歴閲覧、および全点検結果の訂正・取消が可能 |
| `INSPECTOR` | 点検実施、履歴閲覧、および自分が実施した点検結果の訂正・取消が可能                 |

訂正・取消は点検結果の明細単位とする。操作権限はサーバー側でも検証する。

### 2.3 共通メッセージ

| 種別           | 表示例                                               |
| -------------- | ---------------------------------------------------- |
| 正常終了       | `登録しました。`                                     |
| 更新完了       | `更新しました。`                                     |
| 入力エラー     | `入力内容を確認してください。`                       |
| 認証エラー     | `メールアドレスまたはパスワードが正しくありません。` |
| データなし     | `対象データがありません。`                           |
| システムエラー | `処理中にエラーが発生しました。`                     |

### 2.4 共通ルール

- 必須項目には `*` を表示する。
- 入力エラーは対象項目の近くに表示する。
- 保存処理中は保存ボタンを連続押下できないようにする。
- ログインしていないユーザーが業務画面へアクセスした場合は、ログイン画面へ遷移する。
- 権限のない操作ボタンは非表示、または無効化する。
- 日時は原則として `yyyy-MM-dd HH:mm` 形式で表示する。

## 4. 各画面設計

## 4.1 [01] ログイン画面

### 目的

登録済みユーザーを認証し、設備一覧画面へ遷移させる。

### 入力項目

| No. | 項目名         | 入力形式           | 必須 | 最大長 | 説明                     |
| --: | -------------- | ------------------ | :--: | -----: | ------------------------ |
|   1 | メールアドレス | メールアドレス入力 |  ○   |    255 | ログインIDとして使用する |
|   2 | パスワード     | パスワード入力     |  ○   |    255 | 入力文字をマスク表示する |

### 操作

| ボタン   | 動作                                       |
| -------- | ------------------------------------------ |
| ログイン | 認証に成功した場合、設備一覧画面へ遷移する |

### バリデーション

- メールアドレスは必須とし、メールアドレス形式であること。
- パスワードは必須とする。
- 認証に失敗した場合、入力内容を保持したままエラーメッセージを表示する。ただしパスワードの再表示はしない。
- `active = FALSE` のユーザーはログイン不可とする。

### ワイヤーフレーム

```text
+--------------------------------------------------+
|              設備点検管理システム                |
+--------------------------------------------------+
                    ログイン
メールアドレス *
[____________________________________________]
パスワード *
[____________________________________________]
                  [ ログイン ]
※ 認証エラーメッセージ表示領域
```

## 4.6 [06] 点検項目設定画面

### 目的

設備ごとに使用する点検項目を登録、編集、無効化する。無効化した点検項目は再び有効化できる。

### 一覧表示項目

| No. | 項目名     | 説明                           |
| --: | ---------- | ------------------------------ |
|   1 | 表示順     | 点検画面での表示順             |
|   2 | 点検項目名 | 点検項目の名称                 |
|   3 | 種別       | `NUMERIC` または `BOOLEAN`     |
|   4 | 正常条件   | 数値の正常範囲または正常真偽値 |
|   5 | 説明       | 点検方法や確認事項             |
|   6 | 有効状態   | 有効または無効                 |
|   7 | 操作       | 編集、無効化または有効化       |

### 入力項目

| No. | 項目名     | 入力形式         |   必須   | 最大長・範囲          | 説明                                                 |
| --: | ---------- | ---------------- | :------: | --------------------- | ---------------------------------------------------- |
|   1 | 点検項目名 | テキスト         |    ○     | 100文字               | 点検項目の名称                                       |
|   2 | 種別       | セレクト         |    ○     | `NUMERIC` / `BOOLEAN` | 点検値の入力形式と判定方法を決定する                 |
|   3 | 単位       | テキスト         |    -     | 20文字                | `NUMERIC` の測定単位。`BOOLEAN` では使用しない       |
|   4 | 正常下限値 | 数値             |    -     | 数値                  | `NUMERIC` の正常範囲の下限。未設定なら下限判定しない |
|   5 | 正常上限値 | 数値             |    -     | 数値                  | `NUMERIC` の正常範囲の上限。未設定なら上限判定しない |
|   6 | 正常真偽値 | ラジオボタン     | 条件付き | `TRUE` / `FALSE`      | `BOOLEAN` の場合は必須                               |
|   7 | 説明       | テキストエリア   |    -     | 500文字               | 点検方法や確認事項                                   |
|   8 | 表示順     | 数値             |    ○     | 1以上の整数           | 点検画面での表示順                                   |
|   9 | 有効状態   | チェックボックス |    ○     | `TRUE` / `FALSE`      | 点検項目の有効・無効                                 |

### 操作

| ボタン     | 動作                                   |
| ---------- | -------------------------------------- |
| 新規追加   | 点検項目入力領域を新規登録モードにする |
| 保存       | 点検項目を登録または更新する           |
| 編集       | 選択した点検項目を編集モードにする     |
| 無効化     | `active` を `FALSE` に更新する         |
| 有効化     | `active` を `TRUE` に更新する          |
| キャンセル | 入力中の変更を破棄する                 |
| 戻る       | 設備詳細画面へ戻る                     |

### バリデーション

- 点検項目名は必須とし、100文字以内とする。
- 同一設備内で点検項目名は重複不可とする。
- 種別は必須とし、`NUMERIC` または `BOOLEAN` のみ許可する。
- `NUMERIC` の場合、正常下限値・正常上限値は任意とし、正常真偽値は使用しない。
- `BOOLEAN` の場合、正常真偽値は必須とし、単位・正常下限値・正常上限値は使用しない。
- 正常下限値と正常上限値を両方設定する場合、正常下限値は正常上限値以下とする。
- 単位は20文字以内、説明は500文字以内とする。
- 表示順は必須とし、1以上の整数とする。
- 過去の点検結果から参照されるため、原則として物理削除しない。

### ワイヤーフレーム

```text
+----------------------------------------------------------------------------------+
| 点検項目設定：ポンプA                                               [新規追加]   |
+----------------------------------------------------------------------------------+
| 順 | 点検項目名   | 種別    | 正常条件      | 説明           | 状態 | 操作       |
|  1 | モーター温度 | NUMERIC | 0 ～ 80 ℃     | 表面温度を確認 | 有効 | [編集][無効化] |
|  2 | 油漏れ確認   | BOOLEAN | FALSE が正常 | 漏れの有無確認 | 有効 | [編集][無効化] |
|  3 | 振動確認     | NUMERIC | 0 ～ 10 mm/s  | 振動状態を確認 | 無効 | [編集][有効化] |
+----------------------------------------------------------------------------------+

正常上限値         [ 80 ]
正常真偽値（BOOLEAN選択時）  ( ) TRUE  ( ) FALSE
```

## 4.7 [07] 点検実施画面

### 目的

選択した設備の有効な点検項目を表示し、各項目の実測値または真偽値を入力して点検結果を一括登録する。

`OK` / `NG` は作業者が直接選択せず、点検項目に設定された正常条件と入力値をService層で比較して自動判定する。点検対象外の場合は `NOT_APPLICABLE` として登録する。

### 表示・入力項目

#### 点検ヘッダー

| No. | 項目名     | 入力形式       | 必須 | 説明                                                                   |
| --: | ---------- | -------------- | :--: | ---------------------------------------------------------------------- |
|   1 | 設備コード | 表示のみ       |  -   | 対象設備コード                                                         |
|   2 | 設備名     | 表示のみ       |  -   | 対象設備名                                                             |
|   3 | 点検者     | 表示のみ       |  -   | 認証済みログインユーザー名。ユーザーIDは登録時にシステムが自動設定する |
|   4 | 点検日時   | 表示のみ       |  -   | 登録時にサーバー側で取得した日時を自動設定する。手動入力・変更は不可   |
|   5 | 全体備考   | テキストエリア |  -   | 点検全体の補足                                                         |

#### 点検結果明細

| No. | 項目名       | 入力形式                 | 必須 | 説明                                                         |
| --: | ------------ | ------------------------ | :--: | ------------------------------------------------------------ |
|   1 | 点検項目名   | 表示のみ                 |  -   | 有効な点検項目名                                             |
|   2 | 説明         | 表示のみ                 |  -   | 点検方法や確認事項                                           |
|   3 | 正常条件     | 表示のみ                 |  -   | 点検項目に設定された正常範囲または正常真偽値                 |
|   4 | 測定値・回答 | 数値入力または真偽値選択 |  ○   | `NUMERIC` は数値、`BOOLEAN` は真偽値。対象外の場合は入力不要 |
|   5 | 対象外       | チェックボックス         |  -   | 選択時は `NOT_APPLICABLE` とし、測定値・回答を保持しない     |
|   6 | 備考         | テキスト                 |  -   | 項目ごとの補足。500文字以内                                  |

### 操作

| ボタン     | 動作                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| 保存       | `inspection` と複数の `inspection_result` を同一トランザクションで登録する |
| キャンセル | 入力内容を保存せず設備詳細画面へ戻る                                       |

### バリデーション・登録ルール

- 点検日時は登録時にサーバー側で自動設定し、手動入力・変更を認めない。
- 点検者は認証済みログインユーザーから自動設定し、選択・変更を認めない。
- 対象外でないすべての点検項目について、種別に対応した入力値を必須とする。
- `NUMERIC` では `numeric_value` を使用し、`boolean_value` は使用しない。
- `BOOLEAN` では `boolean_value` を使用し、`numeric_value` は使用しない。
- `NOT_APPLICABLE` の場合、数値結果・真偽結果を保持しない。
- `OK` / `NG` は画面側で判定せず、Service層で自動判定する。
- 項目別備考は500文字以内とする。
- 保存途中で一部だけ登録されないよう、全体を1トランザクションで処理する。
- 有効な点検項目が0件の場合、点検を開始できない旨を表示する。
- 点検結果の登録時に、点検項目名・種別・単位・正常条件を明細へスナップショットとして保存する。

```text
| 油漏れ確認   | 漏れの有無確認 | FALSE が正常 | ( )あり ( )なし| [ ]    | [____]   |
```

OK件数、NG件数、対象外件数は、Service層で自動判定された点検結果のうち、取消されていない結果（`inspection_result.cancelled = FALSE`）のみを集計して表示する。

訂正された点検結果は、訂正後の最新の値および判定結果を集計対象とする。訂正前の値は履歴として保持するが、件数には含めない。

## 4.9 [09] 点検履歴詳細画面

### 目的

選択した1回の点検について、点検ヘッダー、各点検項目の実測値または回答、自動判定結果、および訂正・取消履歴を表示する。

権限に応じて点検結果の訂正・取消を可能とし、変更前後の値、操作理由、操作ユーザー、操作日時を監査履歴として確認できるようにする。

### 点検ヘッダー表示項目

| No. | 項目名     | 説明                                                   |
| --: | ---------- | ------------------------------------------------------ |
|   1 | 点検ID     | 点検を識別するID                                       |
|   2 | 設備コード | 対象設備コード                                         |
|   3 | 設備名     | 対象設備名                                             |
|   4 | 点検日時   | 点検実施時にサーバーが記録した日時。訂正・取消後も不変 |
|   5 | 点検者     | 点検を実施したユーザー名。訂正・取消後も不変           |
|   6 | 全体備考   | 点検全体の備考                                         |
|   7 | 作成日時   | レコード作成日時                                       |

### 点検結果表示項目

| No. | 項目名       | 説明                                                           |
| --: | ------------ | -------------------------------------------------------------- |
|   1 | 表示順       | 点検項目の表示順                                               |
|   2 | 点検項目名   | 点検実施時の点検項目名（スナップショット）                     |
|   3 | 種別         | 点検実施時の `NUMERIC` または `BOOLEAN`（スナップショット）    |
|   4 | 正常条件     | 点検実施時の正常範囲・単位または正常真偽値（スナップショット） |
|   5 | 測定値・回答 | 保存された数値または真偽値。対象外の場合は `-`                 |
|   6 | 判定結果     | `OK`、`NG`、`NOT_APPLICABLE`                                   |
|   7 | 取消状態     | `cancelled = TRUE` の場合は「取消済み」と表示                  |
|   8 | 備考         | 項目ごとの備考                                                 |
|   9 | 操作         | 権限があり取消済みでない明細に「訂正」「取消」を表示           |

### 操作

| No. | 操作 | 説明                                                                                         |
| --: | ---- | -------------------------------------------------------------------------------------------- |
|   1 | 訂正 | 選択した点検結果の測定値・回答、対象外指定、項目別備考を訂正する。訂正理由の入力を必須とする |
|   2 | 取消 | 選択した点検結果を取り消す。取消理由の入力と確認操作を必須とする                             |
|   3 | 戻る | 点検履歴一覧画面へ戻る                                                                       |

### 訂正・取消の権限ルール

- `INSPECTOR` は、自分が実施した点検の結果のみ訂正・取消できる。
- `ADMIN` は、すべての点検結果を訂正・取消できる。
- 権限のないユーザーには訂正・取消操作を表示しない。
- 権限チェックは画面表示だけでなく、サーバー側でも必ず実施する。
- 取消済みの点検結果は再度訂正・取消できない。
- 訂正・取消を行っても、元の点検者と点検日時は変更しない。

### 訂正入力・バリデーション

- 訂正対象は選択した点検結果明細1件とし、訂正前の値・判定結果を確認できるようにする。
- `NUMERIC` の場合は数値、`BOOLEAN` の場合は真偽値を入力する。対象外の場合は測定値・回答を保持しない。
- 訂正後の `OK` / `NG` は、点検実施時に保存した正常条件のスナップショットを使用し、Service層で再判定する。
- 項目別備考は500文字以内とする。
- 訂正理由は必須とし、空白のみの入力を認めない。
- 訂正の保存と監査履歴への記録は同一トランザクションで処理する。

### 取消入力・バリデーション

- 取消対象の点検結果明細と現在値を確認できるようにする。
- 取消理由は必須とし、空白のみの入力を認めない。
- 確定後は対象明細の `cancelled` を `TRUE` とする。物理削除しない。
- 取消状態の更新と監査履歴への記録は同一トランザクションで処理する。

### 訂正・取消履歴表示項目

| No. | 項目名       | 説明                                           |
| --: | ------------ | ---------------------------------------------- |
|   1 | 対象点検項目 | 操作対象の点検結果明細                         |
|   2 | 操作種別     | `CORRECT`（訂正）または `CANCEL`（取消）       |
|   3 | 操作日時     | 訂正・取消を実施した日時                       |
|   4 | 操作ユーザー | 訂正・取消を実施したユーザー                   |
|   5 | 操作理由     | 訂正理由または取消理由                         |
|   6 | 変更前       | 操作前の測定値・回答、判定結果、備考、取消状態 |
|   7 | 変更後       | 操作後の測定値・回答、判定結果、備考、取消状態 |

- 履歴は `inspection_result_history` に追記し、過去の履歴を上書き・削除しない。
- 複数回訂正した場合は、各訂正操作の変更前後を時系列で確認できるようにする。
- 取消時も取消前の結果を監査履歴で確認できるようにする。

### 表示ルール

- `NUMERIC` は保存された数値と点検実施時の単位を組み合わせて表示する。
- `BOOLEAN` は保存された真偽値を「あり / なし」「はい / いいえ」など理解しやすい表現で表示する。表示上の文言と `TRUE` / `FALSE` の対応を一貫させる。
- `NOT_APPLICABLE` の場合、測定値・回答は `-` とし、判定結果を「対象外」と表示する。
- 判定結果はService層で算出・保存された最新の結果を表示する。
- 取消済み明細は「取消済み」を明示し、履歴閲覧は可能とするが訂正・取消操作を許可しない。
- 点検項目の設定が後から変更されても、実施当時のスナップショットを表示する。
