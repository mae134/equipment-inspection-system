# AWS Cost Estimate

## 1. 目的

設備点検管理システムをAWS上へ公開する前に、AWS Pricing Calculatorを利用して初期構成の利用料金を見積もる。

本見積もりでは、以下を目的とする。

- AWS Architecture Designで採用した主要AWSサービスの料金発生ポイントを確認する
- ポートフォリオとして継続運用可能なコストであるかを確認する
- 為替変動や従量課金を考慮したコスト管理方針を決定する
- AWS環境構築へ進むためのGO / NO-GO判断材料とする
- AWS構築時に再見積もりするための基準値を残す

---

## 2. 見積もり条件

初期見積もりは以下の条件で実施した。

```text
見積日       : 2026-09-06
Calculator   : AWS Pricing Calculator
為替レート   : 1 USD = 156.59円
用途         : 就職活動用ポートフォリオ
```

AWS Architecture Designに基づき、コストの予測可能性を優先した小規模構成を前提とする。

主な構成条件は以下とする。

- ECS / Fargateを利用する
- Fargate Taskは1 Taskとする
- RDS PostgreSQLを利用する
- RDSはSingle-AZとする
- Application Load Balancerを利用する
- AWS WAFを利用する
- Route 53を利用する
- CloudWatchへアプリケーションログを出力する
- Docker ImageはECRへ保存する
- Fargate TaskへPublic IPv4を1個割り当てる
- NAT Gatewayは利用しない
- VPC Endpointは利用しない
- ECS Auto Scalingは利用しない
- RDS Multi-AZは利用しない
- Shield Advancedは利用しない

## 3. AWS Pricing Calculator見積もり

AWS Pricing Calculatorによる初期見積もり結果は以下の通り。

| AWSサービス               |        月額見積 |
| ------------------------- | --------------: |
| AWS Fargate               |          $22.50 |
| Amazon RDS for PostgreSQL |          $21.01 |
| Application Load Balancer |          $17.97 |
| Amazon ECR                |           $0.10 |
| Amazon CloudWatch         |           $0.76 |
| Amazon VPC / Public IPv4  |           $3.65 |
| AWS WAF                   |           $6.06 |
| Amazon Route 53           |           $0.90 |
| **合計**                  | **$72.95 / 月** |

年間見積額は以下となる。

```text
72.95 USD × 12か月 = 875.40 USD / 年
```

---

## 4. 日本円換算

見積日時点の為替レートとして以下を使用した。

```text
1 USD = 156.59円
```

月額見積:

```text
72.95 USD × 156.59円
≒ 11,423円 / 月
```

年間見積:

```text
875.40 USD × 156.59円
≒ 137,079円 / 年
```

したがって、主要AWSリソースを通常運用した場合の基準額を以下とする。

```text
約11,400円 / 月
約137,000円 / 年
```

## 5. Calculator外および変動する費用

AWS Pricing Calculatorの結果のみで実際の請求額が確定するわけではない。

以下の費用については別途考慮する。

### 5.1 独自ドメイン

Route 53のHosted ZoneおよびDNS Query料金とは別に、独自ドメインの登録・更新料金が発生する。

取得するドメインおよびTLDはAWS構築時に決定する。

独自ドメイン費用はAWS全体の月額費用と比較して影響が小さいと想定し、本見積もりのAWS月額合計には含めない。

### 5.2 データ転送

実際のアクセス量等によってデータ転送料金が変動する可能性がある。

ポートフォリオ用途では大規模なアクセスを想定しないが、実運用開始後は利用状況を確認する。

### 5.3 税

AWS Pricing Calculatorの見積額には、実際の請求時に適用される税が含まれない場合がある。

実際の請求額についてはAWS Billingで確認する。

### 5.4 為替変動

AWS料金は米ドルを基準として見積もっているため、円換算額は為替レートによって変動する。

特に円安が進行した場合、AWS側の利用量が変化していなくても円換算した月額費用が増加する可能性がある。

## 6. 為替変動を考慮したコスト

AWS Pricing Calculatorの月額見積額 $72.95 を基準として、為替レートによる円換算額の変化を確認する。

|     為替レート |   月額換算 |
| -------------: | ---------: |
|    150円 / USD | 約10,943円 |
| 156.59円 / USD | 約11,423円 |
|    160円 / USD | 約11,672円 |
|    165円 / USD | 約12,037円 |
|    170円 / USD | 約12,402円 |

160円 / USDを超える円安が発生した場合でも、通常運用そのものを異常課金と誤判定しないよう、料金監視には一定の余裕を持たせる。

## 7. コスト管理方針

初期見積もり結果を受け、AWS Architecture Designのコスト管理基準を以下とする。

```text
通常運用想定 : 12,000円前後 / 月
警戒ライン   : 13,000円 / 月
緊急警告     : 14,000円 / 月
緊急停止判断 : 15,000円付近 / 月
```

15,000円は料金のハードキャップではなく、緊急対応を判断するための目安とする。

料金情報には反映遅延が存在する可能性があるため、AWS BudgetsおよびCost Anomaly Detectionを併用する。

通常とは異なる急激なコスト増加を検知した場合は、15,000円への到達を待たずに状況を確認し、必要に応じて緊急対応を行う。

---

## 8. AWSクレジット運用方針

AWS Free Tier等によるクレジットを利用できる場合は、AWS利用料金とは別にクレジット残高を確認する。

運用上の判断基準を以下とする。

```text
残り $50 付近
    -> クレジット消費状況および今後の運用期間を再確認

残り $25 付近
    -> 有料運用への移行、構成縮小、停止のいずれかを判断
```

クレジットを使い切ってから対応するのではなく、残高に余裕がある段階でその後の運用方針を決定する。

---

## 9. 主なコスト要因

今回の見積もりでは、以下の3サービスが主要な固定費となる。

```text
AWS Fargate                  : $22.50 / 月
Amazon RDS for PostgreSQL    : $21.01 / 月
Application Load Balancer    : $17.97 / 月
-----------------------------------------
合計                         : $61.48 / 月
```

全体見積額 $72.95 / 月の大部分を、Fargate、RDS、ALBが占める。

そのため、将来的にコスト削減が必要となった場合は、細かな従量課金サービスよりも、まずこれらの構成および稼働方法を見直す。

## 10. GO / NO-GO判断

初期見積もり結果は以下となった。

```text
AWS利用料金 : $72.95 / 月
円換算      : 約11,423円 / 月
通常運用想定: 12,000円前後 / 月
```

AWS Architecture Designで設定した通常運用想定の範囲内であり、ポートフォリオ公開に必要なAWS構成として許容可能と判断する。

したがって、本見積もり時点での判断は以下とする。

```text
GO
```

ただし、AWS環境構築時にはサービス料金および為替レートが変動している可能性があるため、実際のAWSリソース作成前にPricing Calculatorによる再見積もりを行う。

再見積もり結果が許容予算を大きく超える場合は、AWS構築前に構成または運用方法を見直す。

## 11. 見積もり資料

AWS Pricing Calculatorからエクスポートした見積もり資料を以下で管理する。

```text
docs/design/aws-cost-estimate/
├── aws-cost-estimate.pdf
└── aws-cost-estimate.json
```

PDFは人間による見積内容の確認用、JSONはCalculatorから出力された機械可読データの保存用として利用する。

本ドキュメントは見積もり結果および設計判断を説明する資料として管理する。

---

## 12. 今後の確認事項

AWS構築時および運用開始後に以下を確認する。

- AWS構築直前のPricing Calculator再見積もり
- AWS構築時点の為替レート
- 独自ドメインの実際の登録・更新料金
- 実際のデータ転送量
- 実際のCloudWatch Logs使用量
- AWS Free Tierおよびクレジットの適用状況
- AWS Budgetsの通知設定
- Cost Anomaly Detectionの通知設定
- AWS Billingによる実際の利用料金
- 必要に応じたコスト最適化

見積もりと実績に大きな差が発生した場合は、本ドキュメントおよびAWS Architecture Designを更新する。
