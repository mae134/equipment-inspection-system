# 要求整理書

## 1. 背景・現状の業務課題

### 1.1 背景

本システムは、工場における設備点検業務の効率化を目的として開発する。

対象となる工場では、設備情報および点検記録を紙やExcelで管理していることを想定する。

本書に記載する業務課題および利用者の要求は、ポートフォリオ開発のために設定した架空の業務シナリオに基づく。

### 1.2 現状の業務課題

現状の設備点検業務では、以下の課題がある。

| ID    | 業務課題                                                                 |
| ----- | ------------------------------------------------------------------------ |
| P-001 | 設備情報や点検記録が紙・Excelに分散しており、一元管理できていない。      |
| P-002 | 設備ごとの過去の点検履歴を確認する際、必要な記録を探すのに時間がかかる。 |
| P-003 | 設備ごとに点検項目が異なるため、点検情報の管理が煩雑になっている。       |

### 1.3 改善の方向性

設備情報、点検項目、点検記録をWebシステムで一元管理する。

これにより、設備ごとの点検履歴を容易に参照できるようにし、点検業務の効率化を目指す。

## 2. システムの目的・期待効果

### 2.1 システムの目的

本システムは、工場における設備情報および点検記録を電子化し、点検業務の効率化と情報の一元管理を実現することを目的とする。

利用者はPCのWebブラウザから設備情報を参照し、点検結果の登録および過去の点検履歴の確認を行う。

### 2.2 目的と期待効果

| ID    | 目的                   | 期待する効果                                                           | 対応する業務課題 |
| ----- | ---------------------- | ---------------------------------------------------------------------- | ---------------- |
| G-001 | 設備情報の一元管理     | 設備情報や点検記録を集約し、情報の分散を解消する                       | P-001            |
| G-002 | 点検記録の電子化       | 点検結果をWebシステムへ直接入力し、紙やExcelへの記録・転記作業を減らす | P-001            |
| G-003 | 点検履歴の確認効率向上 | 設備ごとの過去の点検結果を容易に確認できるようにする                   | P-002            |
| G-004 | 点検業務の標準化       | 設備ごとに点検項目を管理し、記録方法のばらつきを減らす                 | P-003            |

### 2.3 利用環境の前提

- PCのWebブラウザから利用する。
- ネットワーク接続が利用可能な環境を前提とする。
- タブレット・スマートフォン向けの専用対応は今回の対象外とする。
- オフラインでの点検記録は今回の対象外とする。

## 3. 想定利用者

### 3.1 利用者の概要

本システムは、工場の設備管理者および設備点検担当者が利用することを想定する。

利用者はPCのWebブラウザからシステムへアクセスし、それぞれの業務を行う。

### 3.2 利用者の役割

| ID    | 利用者                      | 想定する役割                                                                 |
| ----- | --------------------------- | ---------------------------------------------------------------------------- |
| U-001 | 設備管理者（ADMIN）         | 設備情報や点検項目を管理し、設備の状態および点検履歴を確認する。             |
| U-002 | 設備点検担当者（INSPECTOR） | 担当設備の点検を実施し、点検結果を記録する。また、過去の点検履歴を確認する。 |

### 3.3 利用者ごとの業務

#### 設備管理者

- 設備情報の登録・編集・管理
- 設備ごとの点検項目の登録・編集・管理
- 設備の状態および点検履歴の確認
- 点検結果の確認

#### 設備点検担当者

- 点検対象設備の確認
- 設備ごとの点検項目の確認
- 点検の実施および結果の登録
- 過去の点検履歴の確認

### 3.4 権限に関する基本方針

- 設備管理者は設備情報および点検項目を管理する。
- 点検結果の登録は設備点検担当者のみが行う。
- 設備管理者と設備点検担当者の両方が設備情報および点検履歴を閲覧できる。
- 点検記録の修正・削除権限など、詳細な権限は要件定義工程で決定する。

## 4. 対象業務・業務フロー

### 4.1 対象業務

本システムでは、工場における設備情報の管理から点検結果の記録・確認までの業務を対象とする。

| ID    | 対象業務         | 担当者                     | 業務内容                                           |
| ----- | ---------------- | -------------------------- | -------------------------------------------------- |
| B-001 | 設備情報の管理   | 設備管理者                 | 点検対象となる設備の情報を登録・編集する。         |
| B-002 | 点検項目の管理   | 設備管理者                 | 設備ごとに必要な点検項目を登録・編集する。         |
| B-003 | 点検対象の確認   | 設備点検担当者             | 点検する設備および点検項目を確認する。             |
| B-004 | 点検の実施・記録 | 設備点検担当者             | 設備の点検を実施し、結果をシステムに登録する。     |
| B-005 | 点検履歴の確認   | 設備管理者・設備点検担当者 | 設備ごとの過去の点検結果を確認する。               |
| B-006 | 点検結果の確認   | 設備管理者                 | 登録された点検結果を確認し、設備の状態を把握する。 |

### 4.2 基本業務フロー

設備点検業務は、以下の流れで実施する。

1. 設備管理者が点検対象となる設備情報を登録する。
2. 設備管理者が設備ごとの点検項目を登録する。
3. 設備点検担当者がシステムにログインし、点検対象設備を選択する。
4. 設備点検担当者が点検項目を確認し、実際の設備を点検する。
5. 設備点検担当者が点検結果をシステムに登録する。
6. 設備管理者が登録された点検結果を確認する。
7. 必要に応じて、設備管理者または設備点検担当者が過去の点検履歴を参照する。

### 4.3 業務上の基本ルール

- 点検対象の設備情報および点検項目は、設備管理者が管理する。
- 点検担当者は、登録済みの設備および点検項目に基づいて点検を実施する。
- 点検結果の登録は、設備点検担当者のみが行う。
- 登録された点検結果は、設備ごとの点検履歴として保存する。
- 設備管理者および設備点検担当者は、保存された点検履歴を参照できる。
- 点検結果に異常（NG）があった場合は、その結果を点検履歴として保存し、設備管理者が確認できるようにする。
- 異常が発生した設備の修理依頼、対応状況の追跡、修理完了管理は本システムの対象外とする。

### 4.4 詳細な業務ルールの検討事項

以下の事項は、要件定義工程で詳細を決定する。

- 点検の実施頻度や実施期限を管理するか。
- 登録済みの点検結果を修正・削除できるか。
- 点検項目を変更した場合、過去の点検履歴をどのように扱うか。
